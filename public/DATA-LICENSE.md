# Map data

The bundled coastline is simplified Natural Earth country geometry. It is not a navigational chart.

- [Source geometry](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson)
- [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/) — public domain.

The map does not require a tile server or API key.
